# R6 — implementation and offline release validation in progress

**Status:** reopened as `in_progress` after the user asked to continue the
remaining specification work; no R6 user approval is claimed. **Latest tested
implementation:** `b62547eb8237d8cbfdf0dc62a178247598c72e73`. This is a
local release candidate, with external-prerequisite checks still open. Nothing
was pushed, published, deployed, or activated.

The application now joins a searchable repository catalog, node details,
source-specific hosting evidence, bounded relationship map, and Activity view.
The browser API is read-only; collection is a separate, bounded writer. The
small deterministic demo contains 100 repositories, 20 nodes, 300 distinct
hosting relationships, two synthetic sources, and 20 unresolved names. The
target fixture contains 20,000 repositories, 2,000 nodes, 100,000 relationships,
and four synthetic sources. Both stay offline. CLI and HTTP adapters are
fixture-tested, but no live source was verified.

To inspect the small demo, first stop any existing demo supervisor that you
own. The current user-owned demo already occupies ports 3000 and 5173; it was
left running and untouched during R6 validation. From the repository root:

```sh
env -u TMPDIR nix develop --command pnpm demo
```

Open http://127.0.0.1:5173 in Firefox. Search for a named repository and an
exact RID, select a repository and then one of its hosting nodes, inspect the
source evidence and unresolved-name wording, switch map scope and large-host
visibility, and compare Activity's 24-hour window with All retained. The
accessible map list remains usable if Firefox has no WebGL context.

For the synthetic outage and recovery walkthrough, stop the demo, run the
reset command, restart it, and run each scenario from another shell while
inspecting Activity. Reset archives the prior confirmed demo database and
refuses a live or in-use database.

```sh
env -u TMPDIR nix develop --command pnpm demo:reset
env -u TMPDIR nix develop --command pnpm demo
env -u TMPDIR nix develop --command pnpm demo:scenario --name source-outage
env -u TMPDIR nix develop --command pnpm demo:scenario --name source-recovery
```

The outage preserves cached records and opens a coverage gap; recovery closes
the gap. [R5](R5.md) records the exact scenario clock and screenshots. To
prepare a separate live configuration, copy `config/ratlas.example.json` to
ignored `config/ratlas.local.json`, configure only an approved public HTTP
source or dedicated public-only observer, and follow the
[collection instructions](../COLLECTION.md) and
[NixOS runbook](../../deploy/nixos/README.md). The bounded command is:

```sh
env -u TMPDIR nix develop --command pnpm test:live --config config/ratlas.local.json
```
