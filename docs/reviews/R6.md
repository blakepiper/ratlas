## Try the real data

The production UI is running at **http://127.0.0.1:3001/?window=all**. It serves a
saved public snapshot: 14 repositories, one node, 14 hosting relationships, one
unresolved name. The source is the Radicle team's selective seed, not the whole
network. The collector has stopped. The original sample-demo processes were not stopped or replaced; by final
verification they had exited and port 3000 was free.

1. Search `heartwood`, select it, and inspect its source evidence and timestamps.
2. Select the hosting node to see the repositories observed through that seed.
3. Hover the map, pan/zoom, and leave it open through a polling interval; the
   canvas and settled positions should remain stable. On narrow screens use Map
   and Details tabs. Activity exposes the stored history and source coverage.

The ignored local review config uses port 3001, CLI disabled, and its own database
under `.ratlas/live-review/`. After stopping this API, restart from this checkout:

```sh
env -u TMPDIR nix develop --command pnpm start:api --config config/ratlas.review.local.json
```

To refresh that explicitly configured public source for 60 seconds:

```sh
env -u TMPDIR nix develop --command pnpm test:live --config config/ratlas.review.local.json
```

Elsewhere, create an ignored config from `config/ratlas.example.json`, explicitly
configure the public HTTPS source, then follow [collection](../COLLECTION.md).
The local review config and runtime data are intentionally not committed.
`pnpm demo` always uses offline sample data; see the [README](../../README.md).

## Changes and verification

- Stable hover overlay, fixed canvas padding, preserved renderer/camera/layout
  across unchanged polls, and normal-animation regression tests.
- Full experiment telemetry, integer resumable progress, configuration/duration
  guards, stat-only public-observer storage reports, and fatal-error handling.
- Indexed metadata lookup and early exact/FTS filtering. Bounded projection caches
  survive health heartbeats; database triggers invalidate on domain changes,
  including direct SQL source quarantine. Conditional health responses stay fresh.
- Expired live-mode browser fixture and context-loss test race corrected.

`pnpm check` passes formatting, lint/policy, types, **64 deterministic tests,
28 Firefox tests without skips**, and production build. Real WebGL is exercised
at both viewports. The saved live UI also passed isolated Firefox selection and
screenshot checks with no page errors. [Validation](../VALIDATION.md) records
checks, and [performance](../PERFORMANCE.md) gives cold/warm, varied-query,
heartbeat-writer, and actual painted-frame measurements.

The new experiment ran against the configured public source for 60 seconds on
2026-09-26: five requests, 44,912 decoded bytes, 13 telemetry samples, no source
error, exit 0. It ran before the final fatal-error guard and projection migration;
those subsequent changes passed offline regression tests. The review database was
then migrated to the final schema. No 24-hour experiment or live CLI ran.
