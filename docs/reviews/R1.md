## What is ready

The locked Nix environment, source-built SQLite binding, domain identities and
schemas, migrations, writer ownership, source-specific evidence, quarantine-safe
public projections and deterministic small demo are implemented. A read-only API
serves the real database summary and list to the first React screen. The offline
doctor checks native SQLite and the isolated Nix Firefox bundle. Development
startup owns its API and watchers and starts no collector.

The synthetic dataset has exactly 100 repositories, 20 node identities, 300
hosting relationships, two sources, 20 unresolved names and two source-route
disagreements. One repository has three seeders observed through both sources.
Demo time is fixed at 2026-09-25T12:00:00Z; live queries retain real-time behavior.

## Run and inspect

From the repository in a fresh terminal:

```sh
nix develop --command pnpm demo
```

Open http://127.0.0.1:5173 in ordinary Firefox. API: http://127.0.0.1:3000.
Both ports must be free. Ctrl-C stops the supervisor and its own children.
The server is stopped at handoff; no application or collector process is left
running. Startup, occupied-port refusal and final shutdown were actually checked.
The final shutdown report records no remaining owned processes and both ports closed.

A fresh checkout needs `nix develop --command pnpm install --frozen-lockfile` first.
The tool environment's stale TMPDIR required command-scoped `env -u TMPDIR`;

## Limits and next stage

Graph, activity, full search/filter/detail navigation, live collectors and the
complete API are not implemented. Their screen labels say so. No graph rendering
or performance claim is made. Target-scale fixtures, backups and remaining command
contracts belong to later stages; README names the current command limits.

No approved live API or dedicated observer profile is configured. Stage B live
checks will need an explicitly approved public HTTPS endpoint or absolute paths
for an existing dedicated public-only observer's executable/home/socket. The
example enables neither. Missing sources must be reported as a live-test gap;
no personal profile, daemon startup or replication is inferred.

The dependency audit still reports two moderate entries for one usage-inapplicable
Vitest advisory, constrained by Node-only tests. It is not a zero-finding audit.
The build emits two upstream Zod PURE-comment warnings; browser console/page-error
checks pass. Catalog query plans include scans/sorting; target-scale performance
has not yet been measured.

Approved deviations: ESLint/@eslint/js family 10 and better-sqlite3 13.0.3.
The latter fixes the reproduced family-12 native abort. The pnpm doctor name
collision is handled by a Nix wrapper delegating to the same pinned pnpm.
The actual version locks remain the source of truth; freeze them at this gate.
