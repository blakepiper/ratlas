## What works

The desktop layout has a 320px repository pane, flexible map area, and 360px
detail pane; side panes collapse. Below 1024px, explicit List, Map, and Details
tabs keep browsing available. The map remains a labeled Stage D placeholder.

The catalog searches names, descriptions, and exact RIDs, including unresolved
ones. Search waits 250 ms and superseded API requests use the browser abort signal.
Metadata, seeder-count, source, and observation-window filters, sorting, 25-item
pagination, and random selection use the public API. The URL carries filters and
selected entities across refresh and browser history. Search context stays in
place while following repository → observed seeder → related repository links.

Repository details show metadata variants, delegates, source provenance, separate
source-read and announcement times, observed seeder evidence, and disagreements.
Node details show identity, sourced alias, counts, evidence sources, and paginated
related repositories. The clone command is generated from a validated RID, copied
only after a click, and always shown for manual copying. Configured explorer links
require a validated HTTPS mapping and open with `noopener noreferrer`.

Loading, empty dataset, no match, missing metadata, unsupported source schema,
cached collection gap, source conflict, invalid selection, and local API failure
have distinct messages. Error text shown in the UI is generic; the interface does
not expose private or quarantined records. Both themes persist locally. Important
actions use keyboard-accessible HTML controls and move focus to the detail heading.

## Start and inspect

```sh
nix develop --command pnpm demo
```

Open **http://127.0.0.1:5173** in your ordinary Firefox. This is the labeled
**Synthetic demo data** set: 100 repositories, 20 node identities, 300 distinct
hosting relationships, two synthetic sources, and 20 unresolved names. It uses
the local SQLite/API path and contacts no upstream Radicle service. Ctrl-C stops
the supervisor's own API and watchers. No server remains running at handoff;
ports 3000 and 5173 were verified closed after this stage's actual startup test.
The tool environment's stale inherited `TMPDIR` needed `env -u TMPDIR` before
its Nix commands; the normal user command above remains the documented entry.

Please inspect these five interactions before graph work begins:

1. Search **atlas**, open a result, then set **Metadata → Unresolved** or paste an
   unnamed repository's RID into search. Confirm the name fallback and source
   evidence are understandable without metadata.
2. Change the source/window/seeder filters and sorting; try random selection and
   pagination. Confirm results and the URL match the selected controls.
3. Open a repository's observed seeder, follow one of that node's repositories,
   then use Back, Forward, and Refresh. Confirm the search and selected detail
   return as expected.
4. In a narrow Firefox window, switch List, Map, and Details tabs and both themes.
   Confirm the details remain readable. The Map tab should explicitly say it is
   forthcoming, rather than behave like a working graph.
5. Click **Copy clone command** and paste into an ordinary text field to verify
   your actual Firefox clipboard. Inspect first-observed, source-read, and
   announcement wording; a recent source read does not claim a node is online.

  Firefox policy checks, workspace/tool typechecks, **51 deterministic tests**,
